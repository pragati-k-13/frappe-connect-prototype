# Sentence chip icons

The globe (country) and briefcase (industry) on the partners hero's chips, in
the "Centered, no visual" layout. Drawn for Connect on 2026-11-25 in the style
of Frappe Suite's Drive file icons (`../file-types/`): Suite has no globe or
briefcase, so these are not copies. One ink colour, 1.5px stroke, 10% fill on
the shape, one 50% accent (a landmass, the clasp), 24×24.

Use like a lucide class: `<span class="sentence-icon-globe size-6 text-ink-blue-6" />`.
